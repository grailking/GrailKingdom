# 🏰 Grail Kingdom Card and Collectibles Show

Welcome to the official website for Grail Kingdom Card and Collectibles Show - a premier trading card show with a medieval castle theme.

## About

Grail Kingdom is your destination for trading cards, collectibles, and treasures of all kinds. Our castle-themed venue brings together collectors, traders, and enthusiasts to share their passion for:

- Trading Cards (Sports, Pokémon, Magic: The Gathering, Yu-Gi-Oh!, and more)
- Rare Collectibles and Vintage Items
- Expert Vendors and Trusted Dealers
- Special Events, Tournaments, and Meet & Greets

## Website

The website is built with HTML, CSS, and JavaScript featuring:

- **Castle-themed design** with medieval aesthetics
- **Responsive layout** that works on all devices
- **Interactive features** including smooth scrolling and animations
- **Modern design** with a classic royal feel

## How to View

Simply open `index.html` in your web browser to view the website locally.

## Files

- `index.html` - Main website structure
- `styles.css` - Castle-themed styling and responsive design
- `script.js` - Interactive features and animations

The website uses a castle/medieval theme with:
